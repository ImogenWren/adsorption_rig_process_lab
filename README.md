## Program Use

1. Program will connect to ADAM5000 IO unit on startup
2. Press Start Log to begin Data Aquisition
3. File will be saved as per Log Filepath Selection selection on `Settings` Page.
4. If Error is encountered, Error Detection indicator will light. Please check for error message in settings page, then press `Reset`
5. Find Serial Settings under `Chassis Settings` on `Settings` tab
6. Enable Debug mode for additional debugging outputs
7. Sample Rate can be adjusted from 1 Hz to 4 Hz
